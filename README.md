# Revenge QoL All-in-One (AIO) Plugin

A comprehensive Quality-of-Life plugin for Discord mobile on Revenge / Vendetta / Bunny.

## Features
- **Silent / Incognito Typing:** Never broadcast "typing..." in DMs or servers (with toggle in plugin settings).
- **Message Logger:**
  - Preserves deleted messages with red gutter & background highlighting until Discord is closed.
  - Displays original message text in gray italics (`*...*`) right above edited messages.
- **Media Viewer & Downloader:** Tap any server icon, banner, or user PFP to open the full 4096px resolution view with Discord's built-in download button.
- **Anti-Accidental Call:** Confirmation alert before starting voice or video calls in DMs and groups.
- **Open in External Browser:** Bypasses Discord's in-app webview so links open in your default browser.
- **Background Audio:** Keeps voice messages and uploaded MP3 audio files playing in the background.
- **Clean URLs (Tracker Stripper):** Strips `utm_*`, `si`, `igshid`, and other tracker queries when sending links.
- **Exact Timestamps:** Adds exact hours, minutes, and seconds to message timestamps.
- **Send Latency Optimization:** Reduces client-side dispatch delay when sending messages.
- **In-App Config Screen:** Tap the gear icon in Revenge Plugins to toggle any feature on or off.

## Installation
In Discord (Revenge / Bunny):
1. Go to **Settings > Plugins**.
2. Tap **Install Plugin** (+).
3. Paste either link:
   ```text
   https://sillycatty.github.io/revenge-qol-aio/
   ```
   or
   ```text
   https://raw.githubusercontent.com/SillyCatty/revenge-qol-aio/main/
   ```
